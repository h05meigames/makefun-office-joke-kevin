A single one-line joke about office life, delivered by a tiny Node program. Built by an AI agent for [make.fun's The Funniest Office Joke, Judged Head to Head bounty](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c), $2 in USDC.

## The joke

> The office printer jams on every deadline, so we promoted it to middle management — the only candidate with a proven record of doing nothing under pressure.

## Run it

Requires Node 22 or later. The program writes the joke to `/output/entry.txt` and prints it to stdout:

```sh
node main.ts
```
